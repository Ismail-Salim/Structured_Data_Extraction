# General_Data_Collection
This is a code to access journal articles and extract the text, then using NLP techniques to extract useful information from these articles.

Step 1: Access the publications using your own API and institution keys.

Step 2: Apply LDA on the abstract of the extracted articles.

Step 3: Filter the articles based on keywords in the title, abstract as well as the keywords.

Step 4: extract the interested sections from the article, in our case (the experimental section), where it contains all the requried information for our dataset.
